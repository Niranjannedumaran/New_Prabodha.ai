# Prabodha AI — Instant Setup & Run Guide

Just copy and paste the command below into your terminal.

---

## ⚡ 1-Line Copy & Paste (Run Locally)

### For Windows PowerShell:
```powershell
npm.cmd install; npm.cmd run build; npm.cmd run preview -- --port 5173 --host 0.0.0.0
```

### For Windows Command Prompt (CMD):
```cmd
npm.cmd install && npm.cmd run build && npm.cmd run preview -- --port 5173 --host 0.0.0.0
```

Once running, open your browser to:
* **Desktop:** [http://localhost:5173/](http://localhost:5173/)
* **Mobile (same Wi-Fi):** `http://<your-computer-ip>:5173/`

*(Press `Ctrl + C` in the terminal anytime to stop).*

## 💻 1-Click Launchers (No Typing Required)

Simply double-click either file inside the project folder:
* **`start-local.bat`** — Automatically builds and starts the local production server.
* **`start-dev.bat`** — Starts the development server with live reload.

---

## 🛠️ Step-by-Step Commands (If Running Individually)

```powershell
# 1. Install dependencies
npm.cmd install

# 2. Build production bundle (TypeScript check + Vite bundle)
npm.cmd run build

# 3. Start preview server (accessible on local network)
npm.cmd run preview -- --port 5173 --host 0.0.0.0
```
